Remix January 2025: Stop Management in Remix (and more).

February 19, 2025
Transit

You can now ingest, view, update, and export all stop information in Remix.

General Availability. Network Places are now available to all! With this update, Remix is now your single, trusted source of truth for managing your stops data. Powerful new capabilities include: 

  • Unified Network View: View all stops, garages, and parent stations in one consolidated map section.
  • Bulk Management Tools: Easily edit multiple fields, or delete places in bulk. Hint: use the map view to  bulk select (then edit or delete) places.
  • Advanced Filtering Options: Want to better understand your network? Filter by specific properties, like in-service vs unused stops to quickly narrow in on the place type you want to learn about.  

 
 
Transit

Rail Routing is now available in Remix. 

General Availability. Agencies can now  modify their tram, light rail and subway systems using Remix’s drawing functionality! This feature works globally across tram, underground, commuter, and high speed rail paths, including under construction tracks. With rail drawing, you can truly visualize and design your entire network in one place - which means better experiences for transit riders.

 
 
Blocking & Scheduling 

Changing existing blocks just got easier.

Until now, changing trips on an existing block would uncut any block referencing the changed block. This resulted in re-work (and headaches!) for schedulers. With this update, Remix Scheduling will uncut only the pieces directly connected to the trips you’re changing. This makes it easier to iterate on multiple scenarios so you can find the best possible solution for your passengers and operators. Blocking & Scheduling

Working on blocking for your electric fleet? Try using Range Restrictions. 

Remix Blocking now supports vehicle range restrictions, allowing schedulers to automatically create blocks that respect the range of a given vehicle. Of course, this is helpful for CNG and other vehicle types, too! 

 
 
 
Blocking & Scheduling

More blocking improvements: create blocks with a target number of hours. 

Have an older vehicle you’d prefer to assign to shorter blocks? Have a feeling that shorter blocks will cut into your runs more easily? Remix Blocking allows you to input a specific target number of platform hours for a given vehicle. Increased precision leads to better runs for your fleet. 

 

That's all for this month! We'll see you next time.
