Scope
DCTA Planning and Development, and Operations departments are tasked with
designing transit service, analyzing demographic impacts, estimating operating costs,
and comparing any changes to current service. These various scenarios along with
their financial and community impacts must be presented to a variety of audiences
including key decision makers and the public and are constantly re-developed.
Currently this process is complex, can be extremely time consuming, and involves using
various software tools in different programs. The Planning and Development, and
Planning departments are seeking to use Remix to streamline this process and assist in
presentations.
Planning requirements and Remix solutions
Requirement: This planning software must not require any additional software or
hardware, minimize software and demographic updating, and not limit the number of
users.
Currently we are limited to analysis tools in ArcGIS which are powerful but difficult to
use and understand. In addition, we are limited to one desktop user for ArcGIS. In
order to update our demographic files we must download extremely large and complex
demographic files from the US Census.
Solution: Remix uses a Software as a Service (SaaS) model where users
access an on-line platform. Remix is responsible for all demographic data and
software updates. Remix does not limit number of users.
Requirement: Software must permit users to quickly and with minimum training modify
or create new routes and schedules.
Currently the Planning department uses ArcGIS to create new routes and modify
existing service. ArcGIS is difficult to use and maintain skill level. Schedules are
created and analyzed in Microsoft Excel. Because routes and schedules are
maintained and updated separately, there are many opportunities for errors.
Solution: Remix provides a drag and drop interface to create and modify routes
and schedules in real-time. This interface is easy to learn for those using
Window based programs.
